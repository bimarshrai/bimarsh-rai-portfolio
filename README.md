# Bimarsh Rai — Portfolio

Premium personal portfolio for Bimarsh Rai — Web Designer & Developer.

## Stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Projects
NOIR, VOLT, MONUMENT, AURELIA, FORMA, VERDICT, SOLAIRE, MUSE, NEXUS, ORBIT, FRAME, VOW.

All project pages are concept projects with fictional business content where applicable.

## Run locally
```bash
npm install
npm run dev
```

## QA
```bash
npm run lint
npm run build
```


Actual standalone integrations: AURELIA, FORMA, VERDICT, SOLAIRE, MUSE, NEXUS, ORBIT, FRAME and VOW. Original portfolio builds: NOIR, VOLT, MONUMENT.


WhatsApp Cloud API setup instructions are in `WHATSAPP-SETUP.md`.
